# Подготовка к собеседованиям — системный аналитик

Материалы для подготовки к техническим собеседованиям на позицию
системного аналитика (junior–middle) в финтех и бигтех.

## Содержимое

| Файл | Что это |
|---|---|
| [`question-bank.html`](question-bank.html) | Банк из 77 вопросов с ответами. Фильтр по блокам, поиск, английские формулировки. Открывается в браузере, без зависимостей. |
| [`4-week-plan.md`](4-week-plan.md) | Подённый план подготовки на 4 недели с привязкой к программе курса. |

В каждом ответе выделены ключевая формулировка, которую ждёт интервьюер,
и типичная ловушка. Внизу ответа — английские формулировки для собеседований
на английском языке.
