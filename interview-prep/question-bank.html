Банк вопросов — системный аналитик

Финтех / бигтех, уровень junior–middle. Кликни вопрос, чтобы раскрыть ответ. В каждом ответе — ключевая формулировка, которую ждёт интервьюер, и типичная ловушка. Внизу ответа — английские формулировки.
Порядок подготовки: SQL → API → асинхрон → моделирование → домен → поведенческие. Если времени мало, блоки «SQL», «API и интеграции» и «Асинхрон» дают около 70% техсобеса.
